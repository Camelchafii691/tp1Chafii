# Utilisation de l’IA — TP1

Codex a contribué à la réalisation du projet à partir du sujet et des fichiers du professeur : génération et modification de code, configuration, tests, lancement. Il a également effectué les opérations Git et la publication sur GitHub.
Les quatre commits initiaux ont été reconstruits automatiquement après la réalisation du projet et publiés ensemble. Ils décrivent un découpage en étapes, pas la chronologie réelle du travail.

L’étudiant a exécuté le script d’essais avec sa clé Gemini locale. Les résultats enregistrés comprennent les conversations, les JSON et les erreurs demandées. Quatre tests automatisés utilisent un serveur HTTP fictif.

Gemini est le service appelé par l’application. La clé API n’est pas publiée dans le dépôt.
